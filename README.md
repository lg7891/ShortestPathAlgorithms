
# Comparison between Shortest Path Algorithms

This project contains implementation of algorithms, tools and classes used for generating graphs, input and output classes all of which were used in diploma thesis for graduation at Faculty of Computer and Information Science at University of Ljubljana.


## Authors

- [@lg7891 ](https://github.com/lg7891)


## Usage/Examples

Project has comments which are used to guide the user when running test and algorithms. The actual results of the testing are not stored anywhere as this project was used mainly for testing of implementation.

The project runs tests on artificial graphs, which are generated within the project and graphs that present real life examples. The project itself includes two groups of graphs which are located in the /resources folder. All of the files have been downloaded from SNAP (Stanford Large Network Dataset Collection), which can be found at https://snap.stanford.edu/data/.
After adding additional graphs, changes have to be made to the project code in Main.java class in order for them to be used. User should have basic understanding and knowladge of programming in Java.

### Running the project
In order to run the project, no arguments need to be passed.
